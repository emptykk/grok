# 审批状态机（V2 可配置级数）

## 状态
`DRAFT → PENDING_L1 → [PENDING_L2] → [PENDING_L3] → PENDING_INQUIRY → PENDING_ORDER → PENDING_RECEIVE → COMPLETED`  
旁路：`REJECTED` / `CANCELLED`。订单可 `PARTIAL` 部分入库。

## 级数规则（approval_rule）
| 金额区间（默认种子） | levels | 路径 |
|---|---|---|
| 0 ~ 4999.99 | 1 | L1(主管) → 询价 |
| 5000 ~ 49999.99 | 2 | L1 → L2(采购负责人) → 询价 |
| ≥50000 | 3 | L1 → L2 → L3(财务 FINANCE) → 询价 |

提交时写入 `required_levels` 并占用预算科目；驳回/撤回释放占用。

## 角色映射
- L1：DEPT_MANAGER / ADMIN
- L2：PURCHASE_MANAGER / ADMIN
- L3：FINANCE / ADMIN
