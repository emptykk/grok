# 08 答辩演示增强

在原有采购闭环与嵌入式 AI 之上，补齐「看起来像已落地产品」的展示层。不引入微服务，不替换技术栈。

## 新增 / 扩展 API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/dashboard/summary` | 增加 `pendingL3`、`monthlyTrend`、`categoryShare`、`recentFlow`、`budgetPressure`、`contractsExpiring` |
| GET | `/api/dashboard/process` | 全流程节点数量与样例单据 |
| GET | `/api/approvals/{requestId}/timeline` | 单条申请审批轨迹（提交、L1/L2/L3、询价、订单、入库、完成） |
| GET | `/api/suppliers/{id}/profile` | 雷达、风险标签、准时率/合格率、历史订单与摘要 |
| GET | `/api/ops/overview` | 管理员：健康、任务目录与执行记录、AI 脱敏配置、审计摘要 |
| GET | `/api/logs` | 增加 `username/module/action/keyword/success` 筛选 |
| GET | `/api/logs/{id}` | 日志详情 |
| GET | `/api/logs/export` | 操作日志 CSV（UTF-8 BOM） |
| GET | `/api/budgets/export` | 预算科目 Excel |
| POST | `/api/ai/anomaly-analysis` | 增加结构化 `findings` 与 `source`（llm / rule） |
| GET | `/api/auth/me` 与登录用户 | 增加 `dataScope`、`dataScopeLabel` |

沿用既有接口：`POST /api/jobs/inventory-alert`、`POST /api/jobs/contract-expiry`（现在会写入 `job_run_log`）、`GET /api/knowledge/qa-history`、`GET /api/inquiries/{id}/compare-report/export`、`GET /api/requests/export`、消息已读接口。

## 表结构

新增 `job_run_log`（任务编码、触发方式 MANUAL/SCHEDULE、状态、摘要、耗时、操作者）。`backend/src/main/resources/db/schema.sql` 与 `docs/schema.sql` 已同步。H2 启动时会重建库并灌入覆盖全状态的申请、审批、询价、订单、合同、消息、评分和制度分段。

- 流程总览：可点击状态机
- 审批页：真实时间轴
- 供应商画像：ECharts 雷达 + 风险标签
- 全局命令面板：Ctrl/⌘ K

- `/ops` 运行中心、日志筛选导出、异常解读、制度问答高亮与历史、消息角标、导出与数据范围芯片

## 第二轮（打印 / 导览 / 视觉）

- 打印页：`/print/requests/:id` 申请单、`/print/inquiry/:requestId` 比价表。申请列表和询价页有「打印预览」，样式按 `window.print` 隐藏工具条。
- 登录页：slogan、角色说明卡片依次浮入，网格与光晕动画。点卡片仍是一键登录。
- 答辩导览固定六步：工作台 → 流程 → 审批 → 画像 → 运行中心 → 大模型配置。可跳过；完成后写入 `localStorage`（`ip-tour-seen-v2`），顶栏按钮可强制重播。
- 空状态改为插画加说明，申请/订单/合同缺数据时可去创建；申请、订单、库存、合同有骨架屏。
- 种子补了一张已取消申请，询价单 9 增加华信最低价 9100，流程节点均有样例。
- 比价页：最低价标签、进度条、对比表高亮，导出与打印按钮加大。
- 合同行内「查看风险摘要」打开抽屉，30 天内到期标红。
- 库存预警按当前/安全库存着色：低于为红，1.2 倍以内为黄，否则为绿。

## 第三轮（AI 展示 / 规则 / 铃铛 / 脚本）

- 制度问答的引用改成编号卡片，命中词仍高亮。
- 异常解读每张卡片可跳到供应商、预算、订单或工作台。
- 管理周报按「指标 / 风险提示 / 正文」排成简报，不再只是一大段文本框。

- KPI 卡片入场错开；登录、审批通过、全部已读会放一小撮 CSS 纸屑。
- `/demo-script` 列出今晚演示顺序，点击即跳转。

## 第四轮（时间机器 / 对比 / 预算仪表）

- `GET /api/requests/{id}/trace` 把申请、审批、询价轮次、订单、入库差异、退换货、合同、发票、付款收成一条时间轴。页面 `/trace/:requestId`，流程总览可从样例单跳入。建议讲 `PR20260618001`（id=1）。
- `/suppliers/compare` 勾选 2–3 家，并排雷达和指标表。
- 预算页改为执行仪表：进度环、≥80% 预警列表，点击下钻 `/requests?budgetSubjectId=`。申请列表接口增加可选参数 `budgetSubjectId`。
- 图表随暗色主题重建；滚动条和文字选中态统一。
- 按 `?` 打开快捷键面板（输入框里不会触发）。
- 运行中心汇总申请、预算、比价、物资、供应商、订单、日志和制度上传的入口。

## 已知限制

- 无 DeepSeek Key 时，周报、审批助手、比价结论、异常解读和制度问答走规则或检索片段，不调用外网。
- 雷达图上带 `*` 的维度表示没有评分记录，用准入分作基线，不是实测均值。
- 准时率只统计「有期望到货日且已入库」的订单。
- 数据范围在界面上明示，列表过滤仍沿用原有服务里的 SELF/DEPT/ALL 实现，本轮没有重写每一张业务表的查询。
- H2 每次启动会 `DROP` 并重建，演示中新增的单据在重启后回到种子数据。
- 命令面板与答辩导览只覆盖已登录后的主框架，不在登录页出现。
