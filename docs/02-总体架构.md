# 总体架构设计

## 1. 逻辑架构

```
┌─────────────────────────────────────────────┐
│                 浏览器 (Vue3 SPA)            │
│  登录 │ 申请 │ 审批 │ 询价 │ 订单 │ 库存 │ AI │
└──────────────────┬──────────────────────────┘
                   │ HTTP/JSON + JWT
┌──────────────────▼──────────────────────────┐
│              Spring Boot 后端                │
│  Controller → Service → Mapper (MyBatis-Plus)│
│  Security(JWT) │ AI Service │ RAG Service    │
└───────┬──────────────────────────┬──────────┘
        │                          │
   ┌────▼────┐              ┌──────▼──────┐
   │ MySQL 8 │              │ DeepSeek API│
   │ (业务库) │              │ (LLM/可选)  │
   └─────────┘              └─────────────┘
        │
   本地 uploads/（附件与制度原文）
   本地 rag-index/（分段索引 JSON）
```

## 2. 分层说明
- **表现层**：REST Controller，统一 `Result<T>` 响应；Knife4j 文档  
- **业务层**：采购流程状态流转、权限校验、AI/RAG 编排  
- **持久层**：MyBatis-Plus Mapper；事务在 Service 层  
- **安全层**：Spring Security + JWT，无状态鉴权；方法级可按角色限制  

## 3. 前端结构
- `views/`：按业务模块划分页面  
- `api/`：Axios 封装，自动带 Token  
- `stores/`：Pinia 用户与权限  
- `router/`：路由守卫按角色过滤菜单  

## 4. 部署示意
前端 Nginx（或 Vite 开发服）→ 后端 `8080` jar → MySQL `3306`。  
开发环境可用 H2 `MODE=MySQL` 快速启动（见 README）。
