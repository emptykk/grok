# 基于大模型的智能采购管理系统 — 需求分析

## 1. 项目背景与目标

面向中小企业内部采购场景，建设一套前后端分离的智能采购管理系统。系统覆盖采购申请、两级审批、询价比价、下单、入库与统计分析全流程，并接入大语言模型（DeepSeek），提供：

1. 自然语言生成采购申请明细  
2. 供应商智能推荐（规则候选 + 大模型说明）  
3. 采购制度文档智能问答（RAG）

技术栈：Vue 3 + Element Plus + Pinia + Vue Router；Spring Boot 3 + MyBatis-Plus + Spring Security(JWT) + MySQL 8；DeepSeek OpenAI 兼容 API；Knife4j 接口文档。

## 2. 用户角色（RBAC）

| 角色编码 | 角色名称 | 职责 |
|---|---|---|
| APPLICANT | 采购申请人 | 发起/撤回申请，查看本人单据，使用 AI 生成明细 |
| DEPT_MANAGER | 部门主管 | 一级审批（通过/驳回/意见） |
| PURCHASE_MANAGER | 采购负责人 | 二级审批、询价比价、下单、查看 AI 推荐 |
| WAREHOUSE | 仓管 | 到货验收、入库、库存与预警查看 |
| ADMIN | 系统管理员 | 用户角色、主数据、制度文档、系统配置、操作日志 |

## 3. 功能需求摘要

### 3.1 系统管理
登录/退出、JWT 鉴权、修改密码；用户/角色管理；操作日志；数据字典。

### 3.2 主数据
物资档案、供应商档案、库存台账与安全库存预警。

### 3.3 采购主流程
申请 → 一级审批 → 二级审批 → 询价比价 → 下单 → 入库 → 完成。  
状态机见《04-审批状态机》。

### 3.4 智能功能
- **AI 写申请**：自然语言 → 结构化明细（品名、数量、单价、预算、备注）  
- **供应商推荐**：历史价 + 评级规则过滤 → LLM 生成推荐理由  
- **制度 RAG**：上传 PDF/Word → 分段索引 → 问答并返回依据片段  

### 3.5 通用能力
分页查询、附件上传、Excel 导出、Swagger/Knife4j。

## 4. 非功能需求
- 角色数据隔离；审批与关键操作可追溯  
- 大模型不可用时主流程可手工完成并给出明确提示  
- 可本地一键演示（MySQL 或 H2 兼容模式）

## 5. 范围外
可视化复杂 BPM、电子签章、对接外部电商/ERP、多法人、移动 App、微服务拆分。

## 6. 答辩演示剧本
申请人 AI 填单 → 主管通过 → 采购负责人通过 → AI 推荐并比价下单 → 仓管入库 → 看板变化；另演示制度上传与带依据问答。
