# 库表设计（V2）

字符集：utf8mb4。主键均为自增 BIGINT。完整 DDL：`backend/src/main/resources/db/schema.sql`。

## 系统
- `sys_user`：+email
- `sys_role`：+data_scope（SELF/DEPT/ALL）
- `sys_user_role`、`sys_oper_log`（+method/request_uri/cost_ms/success）
- `sys_message`：站内消息
- `email_send_log`：邮件发送模拟日志

## 主数据
- `material`、`inventory`
- `supplier`：+admission_score、blacklisted、blacklist_reason、last/next_review_date
- `supplier_score_record`：评分历史
- `budget_subject`：预算科目（budget_year、total/used_amount）
- `material_template`：智能填单常用物资模板

## 采购主流程
- `purchase_request`：+budget_subject_id、required_levels
- `purchase_request_item`、`purchase_approval`
- `approval_rule`：按金额区间配置 1/2/3 级审批
- `inquiry`：+current_round
- `inquiry_quote`：+round_no、negotiate_note
- `purchase_order` / `purchase_order_item`
- `inbound_order`：+diff_flag、diff_remark
- `inbound_order_item`
- `return_order` / `return_order_item`：退货/换货
- `contract_info`：合同（风险摘要 risk_summary）
- `invoice`、`payment_request`

## 知识库
- `knowledge_doc`、`knowledge_chunk`
- `knowledge_qa`：问答历史（references_json、highlights_json）
- `attachment`
